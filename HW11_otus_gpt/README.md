# OTUS Генератор Шуток 😂

AI-генератор шуток на основе модели GPT-2 от HuggingFace.
**Домашнее задание #11** для курса OTUS Python.

## Возможности

- 🎭 **Множество категорий**: Программистские шутки, папины шутки, каламбуры и общий юмор
- 🎨 **Настраиваемая генерация**: Регулируйте температуру, длину и креативность
- 💻 **CLI интерфейс**: Простой инструмент командной строки
- 🌐 **Веб-интерфейс**: Интерактивное веб-приложение на Streamlit
- 🤖 **Предобученная модель**: Использует DistilGPT-2 (82M параметров)

## Использование

### 1. Веб-интерфейс (Рекомендуется)

Запустите Streamlit приложение:

```bash
streamlit run app.py
```

Затем откройте браузер по адресу `http://localhost:8501`

**Возможности:**
- Выбор категории шуток из выпадающего списка
- Регулировка ползунка креативности
- Генерация нескольких шуток за раз
- Использование пользовательских промптов
- Копирование сгенерированных шуток

### 2. Интерфейс командной строки

Сгенерировать одну шутку:
```bash
python cli.py
```

Сгенерировать программистскую шутку:
```bash
python cli.py --category programming
```

Сгенерировать 3 папиных шутки:
```bash
python cli.py --category dad_jokes --num 3
```

Использовать пользовательский промпт:
```bash
python cli.py --custom "Write a joke about Python programming:"
```

Настроить креативность (температуру):
```bash
python cli.py --category puns --temperature 1.2
```

**Опции CLI:**
- `--category, -c`: Категория шуток (programming, dad_jokes, puns, general)
- `--num, -n`: Количество шуток для генерации
- `--temperature, -t`: Креативность (0.1-2.0, по умолчанию 0.8)
- `--max-length, -l`: Максимальная длина в токенах
- `--custom`: Пользовательский промпт
- `--model, -m`: Название модели HuggingFace

### 3. Python API

Используйте в своем коде:

```python
from joke_generator import JokeGenerator

# Инициализация генератора
generator = JokeGenerator()

# Генерация шутки
joke = generator.generate_joke(
    category='programming',
    temperature=0.8,
    max_length=100
)
print(joke)

# Генерация нескольких шуток
jokes = generator.batch_generate(
    category='dad_jokes',
    num_jokes=3
)
for joke in jokes:
    print(joke)
    print("---")
```

## Информация о модели

- **Модель**: DistilGPT-2
- **Размер**: 82M параметров
- **Тип**: Авторегрессионная языковая модель
- **Источник**: HuggingFace Transformers
- **Архитектура**: GPT-2 (Generative Pre-trained Transformer)

### Почему DistilGPT-2?
- Меньше и быстрее чем GPT-2
- Хороший баланс качества и скорости
- Хорошо работает на CPU
- Идеально для образовательных проектов

## Объяснение параметров

### Temperature (0.1 - 2.0)
- **Низкая (0.1-0.5)**: Более предсказуемые, безопасные шутки
- **Средняя (0.6-1.0)**: Сбалансированная креативность
- **Высокая (1.1-2.0)**: Очень креативно, может быть бессмысленно

### Max Length (Максимальная длина)
- Количество токенов (примерно слов) для генерации
- Рекомендуется: 50-150 токенов
- Больше = более полные шутки, но медленнее

### Top-p (Nucleus Sampling)
- По умолчанию: 0.9
- Контролирует разнообразие выбора слов
- Выше = более разнообразный словарь

## Решение проблем

### Ошибка нехватки памяти
- Уменьшите `max_length`
- Используйте CPU вместо GPU
- Закройте другие приложения

### Медленная генерация
- Модель загружается при первом запуске (~250MB)
- Генерация занимает 5-30 секунд в зависимости от железа
- Используйте меньший `max_length` для более быстрых результатов

### Плохое качество шуток
- Настройте `temperature` (попробуйте 0.7-0.9)
- Попробуйте разные категории
- Используйте пользовательские промпты для лучшего контроля
- Примечание: GPT-2 не дообучена на шутках, поэтому качество варьируется

2. Токенизация текста промпта
3. Авторегрессивная генерация токенов
4. Применение temperature и top-p sampling
5. Декодирование токенов обратно в текст
6. Очистка и форматирование вывода
