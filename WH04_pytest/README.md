# Scoring API - Модульные тесты

Модульные тесты для HTTP API сервиса скоринга.

## Структура проекта

```
WH04_pytest/
├── api.py              # API модуль
├── scoring.py          # Функции скоринга
├── store.py            # Модуль хранилища
├── tests/              # Модульные тесты
│   ├── test_scoring.py # Тесты scoring.py
│   ├── test_store.py   # Тесты store.py
│   └── test_api.py     # Тесты api.py
├── requirements.txt    # Зависимости
└── pytest.ini         # Конфигурация pytest
```

## Установка

```bash
pip install -r requirements.txt
```

## Запуск тестов

### Все тесты
```bash
pytest
```

### Отдельные модули
```bash
pytest tests/test_scoring.py -v
pytest tests/test_store.py -v
pytest tests/test_api.py -v
```

### С покрытием кода
```bash
pytest --cov=. --cov-report=html
```

## Описание тестов

### test_scoring.py (28 тестов)
- Тесты функции `get_score` с разными параметрами
- Тесты функции `get_interests` 
- Параметризованные тесты комбинаций полей
- Тесты работы с кешем и обработки ошибок

### test_store.py (31 тест)
- Тесты MockStore для изолированного тестирования
- Тесты retry логики и обработки ошибок
- Тесты RedisStore и MemcacheStore с моками
- Тесты фабрики хранилищ

### test_api.py (32 теста)
- Тесты валидации запросов и полей
- Тесты авторизации и обработки методов
- Тесты классов Request и их наследников
- Тесты системы валидации полей

## Основной функционал

### Store модуль
- Retry логика с экспоненциальной задержкой
- Поддержка Redis, Memcached и MockStore
- Разделение кеша и персистентного хранилища
- Обработка таймаутов и ошибок подключения

### Scoring функции
- `get_score()` - вычисление скора с кешированием
- `get_interests()` - получение интересов клиентов
- Работа при недоступности хранилища

### API валидация
- Система валидации полей (CharField, EmailField, PhoneField и др.)
- Валидация запросов (MethodRequest, OnlineScoreRequest, ClientsInterestsRequest)
- Авторизация пользователей и админов
