# HTTP Server

Простой многопоточный HTTP сервер, реализующий основные функции протокола HTTP/1.1.

## ✅ Функциональность

### Поддерживаемые HTTP методы:
- **GET** - возвращает содержимое файлов (200/403/404)
- **HEAD** - возвращает только заголовки (200/404)  
- **Остальные методы** - возвращают 405 Method Not Allowed

### Обработка путей:
- `/file.html` → `DOCUMENT_ROOT/file.html`
- `/directory/` → `DOCUMENT_ROOT/directory/index.html`
- Поддержка URL декодирования (%XX последовательности)
- Защита от выхода за пределы DOCUMENT_ROOT (блокировка `../`)

### HTTP заголовки:
**Обязательные для всех ответов:**
- `Server: httpd/1.0`
- `Date: [RFC compliant format]`
- `Connection: close`

**Дополнительные для 200 ответов:**
- `Content-Length: [размер файла]`
- `Content-Type: [MIME тип]`

### MIME типы:
- `.html` → `text/html`
- `.css` → `text/css`
- `.js` → `application/javascript`
- `.jpg/.jpeg` → `image/jpeg`
- `.png` → `image/png`
- `.gif` → `image/gif`
- `.swf` → `application/x-shockwave-flash`

## 🚀 Запуск

### Основные параметры:
```bash
python httpd.py -r <DOCUMENT_ROOT> [-p PORT] [--host HOST]
```

**Примеры:**
```bash
# Запуск на порту 80 с папкой ./www
python httpd.py -r ./www -p 80

# Запуск на порту 8080 с кастомной папкой
python httpd.py -r /path/to/files -p 8080

# Запуск на всех интерфейсах
python httpd.py -r ./www --host 0.0.0.0 -p 8080
```

### Параметры:
- `-r, --document-root` - путь к корневой папке с файлами (обязательный)
- `-p, --port` - порт для прослушивания (по умолчанию: 80)
- `--host` - хост для прослушивания (по умолчанию: localhost)

## 📐 Архитектура

- **Многопоточная архитектура** - каждое соединение обрабатывается в отдельном потоке
- **HTTP/1.1** совместимость
- **Безопасная обработка путей** - защита от directory traversal атак
- **Правильные MIME типы** для всех поддерживаемых форматов
- **Корректная обработка ошибок** с соответствующими HTTP кодами

## 🔧 Требования

- Python 3.6+
- Права доступа к указанному порту (для порта 80 нужны права администратора)
